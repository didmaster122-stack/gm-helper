## Заметки для следующих этапов

- Этап 6: выбор арта — готовый `ArtPicker` из `modules/library` (props `libraryRoot`, `preferredSystem`, `onPick`). Токены — `useLibraryStore` (`tokens`, `tokensByArt`), тип `Token` из `modules/library`; `revealArt(id)` открывает арт в библиотеке. Выбор токена в `ArtPicker` ещё нужно добавить.
- Токены хранят свой путь (`tokens.rel_path`) явно: при переименовании арта вне приложения файл токена сохраняет старое имя и остаётся привязан.
- Этап 8: при смене корня библиотеки записи старой папки остаются как «Файл отсутствует» — их очистка входит в пункт «Очистка записей».
- Этап 4: формат карты — `toJson` / `fromJson` в `modules/battlemap/domain/format.ts` (поле `version`, клетки в RLE); его же использовать для `.gmmap.json`. Отрисовка — `drawScene` / `drawCell` в `modules/battlemap/render.ts` (узоры заливаются `CanvasPattern` из кэша плиток); для PNG можно рисовать сцену в OffscreenCanvas с нужным размером клетки.
- Тестовая библиотека: `node scripts/make-test-library.mjs <папка вне репозитория>` — 1400+ PNG по системам и группам, плюс «Не разобрано», пустая группа и `_tokens`.
