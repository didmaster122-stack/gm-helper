Этапы идут по порядку. Каждый этап заканчивается рабочим приложением, которое можно запустить и использовать. Подробности поведения — в [spec.md](spec.md).

Текущая версия: **v0.2**. Текущий этап: **14**

## Заметки для следующих этапов

- Интерфейс (этап 8): цвета только через токены `shared/ui/styles/tokens.css`; кнопки — `Button` / `IconButton` / `Segmented` из `shared/ui`; холсты берут цвета темы через `useThemeColor`.
- Бэкап кампании (этап 11): `modules/backup/` (конверт файла `domain/format.ts`, `BACKUP_VERSION`, сценарии в `service.ts`). Секции читает и пишет модуль-владелец: `relations/domain/backup.ts`, `timeline/domain/backup.ts`, `battlemap/domain/backup.ts`, ссылки на арты — `library/domain/artRefs.ts`. Новые данные кампании (новая таблица) нужно добавить и в бэкап, и в `deleteCampaign`; при изменении формата — конвертер в `parseBackup`.
- Токены хранят свой путь (`tokens.rel_path`) явно: при переименовании арта вне приложения файл токена сохраняет старое имя и остаётся привязан.
- Этап 4: формат карты — `toJson` / `fromJson` в `modules/battlemap/domain/format.ts` (поле `version`, клетки в RLE); его же использовать для `.gmmap.json`. Отрисовка — `drawScene` / `drawCell` в `modules/battlemap/render.ts` (узоры заливаются `CanvasPattern` из кэша плиток); для PNG можно рисовать сцену в OffscreenCanvas с нужным размером клетки.
- Общий текстовый поиск (регистр, `ё`/`е`, опечатки) — `shared/search/text.ts`; им пользуются библиотека артов и галерея карт. Для поиска персонажей на этапе 6 брать его же.
- Тестовая библиотека: `node scripts/make-test-library.mjs <папка вне репозитория>` — 1400+ PNG по системам и группам, плюс «Не разобрано», пустая группа и `_tokens`.
- Тестовая музыка: `node scripts/make-test-music.mjs <папка вне репозитория>` — 500+ коротких WAV по категориям и подборкам, 4 длинных трека для проверки перехода, «Не разобрано» и пустая подборка.
- Музыка (этап 9): общая логика каталогов — `shared/catalog/` (пути, сопоставление по хэшу, дерево, план импорта, диалог импорта). Плеер — `modules/music/player.ts` (две `<audio>` для плавного перехода, состояние в `usePlayerStore`, живёт вне React). Вкладки «Слушать / Редактировать» — в `MusicScreen.tsx`, «В редактор» — в `TrackPanel.tsx`.
- Редактор музыки (этап 10): `modules/music/editor/`. Модель и операции — `domain/project.ts` (секунды, клипы без наложений), расписание воспроизведения — `domain/schedule.ts` (общее для живого звука и сведения), волна — `domain/waveform.ts`. Web Audio — `audio.ts`, сведение и MP3 (`wasm-media-encoders`, 192 кбит/с в воркере `mp3.worker.ts`) — `mixdown.ts`. Новый файл пишется через `writeNewFile` (не перезаписывает). Проект не сохраняется между запусками (вне MVP).
