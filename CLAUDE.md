# GM Helper — правила проекта

Десктопное приложение-помощник для game master'а. Что делает программа: [docs/spec.md](docs/spec.md). План по этапам и текущий этап: [docs/plan.md](docs/plan.md).

## Перед работой

- Прочитай нужный раздел `docs/spec.md` и текущий этап в `docs/plan.md`.
- Работай в рамках текущего этапа. Функции из «Вне рамок MVP» не добавляй без прямой просьбы.
- Если задача расходится со спецификацией, сначала спроси, потом обнови `docs/spec.md` вместе с кодом.
- После этапа отметь выполненные пункты в `docs/plan.md`.

## Стек

- Tauri 2 + React 19 + TypeScript (strict, `noUncheckedIndexedAccess`) + Vite.
- Состояние: Zustand. Граф отношений: React Flow (`@xyflow/react`). Хронология: обычный HTML с вертикальной прокруткой и SVG-стрелками (`modules/timeline/TimelineBoard.tsx`, раскладка — чистая функция `domain/layout.ts`). Баттлмап: HTML Canvas 2D (без DOM-элемента на клетку).
- Хранение: SQLite через `@tauri-apps/plugin-sql`. Файлы: `@tauri-apps/plugin-fs`, `@tauri-apps/plugin-dialog`.
- Обработка изображений (миниатюры, токены, экспорт PNG): Canvas / OffscreenCanvas на стороне TS.
- Rust: только подключение плагинов, разрешения и то, что нельзя сделать на TS (watcher файлов, перемещение в корзину, хэширование больших файлов при необходимости). Бизнес-логику в Rust не пиши.
- Новую зависимость добавляй, только если без неё заметно сложнее. Причину укажи в описании коммита.

## Структура

```
src/
  app/            # оболочка, навигация (useAppStore), первый запуск
  modules/
    campaigns/    # кампании: repo, store, переключатель, форма, RequireCampaign
    library/      # арты, индекс, поиск, токены; domain/ — чистая логика, service.ts — сценарии fs+БД, ArtPicker — для других модулей
    battlemap/    # модель сетки, редактор, экспорт
    relations/    # персонажи, фракции, граф
    timeline/     # дорожки, события, связи событий
    settings/
  shared/
    db/           # подключение, миграции, репозитории
    fs/           # единственное место прямой работы с файловой системой
    ui/           # общие компоненты
    i18n/ru.ts    # все строки интерфейса
src-tauri/        # Rust-часть Tauri
docs/
```

- Модуль не импортирует внутренности другого модуля, только его `index.ts`. Модули не импортируют `app/`: нужные данные (например `libraryRoot`) приходят через props.
- Экраны, которые зависят от кампании, оборачиваются в `RequireCampaign` и получают `campaign` через props.
- Доменная логика (модель баттлмапа, поиск, раскладка хронологии, расчёт кадрирования токена) — чистые TS-функции без React и Tauri, чтобы их можно было тестировать.

## Правила кода

- TypeScript strict, без `any` (если очень нужно — `unknown` с проверкой). ESLint и Prettier должны проходить.
- Идентификаторы, комментарии и коммиты — на английском. Все тексты интерфейса — на русском, только через `shared/i18n/ru.ts`, без строк прямо в JSX.
- ID сущностей — UUID (строки). Даты — ISO 8601 в UTC.
- Пути к артам в БД — **относительные** к корню библиотеки, с разделителем `/`. Абсолютный путь собирается только в `shared/fs`.
- Запросы к БД — только в репозиториях `shared/db` или `modules/*/repo.ts`, не в компонентах.
- Любое изменение схемы БД — новая миграция в `shared/db/migrations.ts`. Существующие миграции не редактируй. Миграции применяются при запуске (`getDb()`), перед ними делается `VACUUM INTO` в файл `gm-helper.backup-v<N>-<время>.db` рядом с базой.
- БД: `%APPDATA%\com.gmhelper.app\gm-helper.db`. Плейсхолдеры параметров — `?`. Репозитории принимают `Db` (интерфейс из `shared/db/types.ts`), чтобы тесты могли подставить `createMemoryDb()` (`node:sqlite`).
- Внешние ключи не включены (PRAGMA действует на одно соединение, а плагин использует пул), поэтому зависимые записи удаляет репозиторий. При добавлении таблиц кампании дополни `deleteCampaign`.
- SQLite `NOCASE` не понимает кириллицу: сортируй по имени в TS через `localeCompare(…, "ru")`.
- Плагин sql выполняет каждый вызов на любом соединении пула, поэтому транзакция из нескольких вызовов `execute` ненадёжна. Пакетные записи собирай в один скрипт через `runScript` + `sqlLiteral` (`shared/db/script.ts`). Одиночные запросы — обычные `execute` с `?`.
- Форматы JSON (баттлмап, бэкап кампании) содержат поле `version`. При изменении формата добавь конвертер со старой версии.

## Безопасность данных пользователя

- Никогда не удаляй, не перезаписывай и не перемещай файлы артов без явного подтверждения в UI. Удаление — через корзину.
- Приложение может свободно перезаписывать только свои файлы: токены в `_tokens/`, миниатюры и кэш в каталоге данных приложения.
- Перед миграцией БД делай копию файла базы.
- В тестах не трогай реальную библиотеку пользователя, используй временные каталоги и фикстуры.

## Тесты и проверки

- Vitest для доменной логики: модель сетки и регионов, поиск (регистр, `ё`/`е`, нечёткость), сопоставление файлов по хэшу, кадрирование токена, миграции форматов.
- Компоненты тестируй выборочно (React Testing Library), когда логика в UI нетривиальна.
- Перед тем как считать задачу готовой: `npm run lint`, `npm run typecheck`, `npm test`. Для UI-изменений запусти приложение и проверь вручную.

## Команды

```
npm install
npm run tauri dev     # запуск в режиме разработки (первая сборка Rust ~3 мин)
npm run lint
npm run typecheck
npm test              # vitest run; npm run test:watch — в режиме наблюдения
npm run format        # prettier --write .
npm run tauri build   # сборка установщика
```

- Права плагинов Tauri — в `src-tauri/capabilities/default.json`. Библиотека лежит в произвольной папке пользователя, поэтому операциям fs, которые с ней работают (чтение, mkdir, rename, copy, remove, watch), выдан scope `**`. Запись файлов (`write-file`) разрешена только в `$APPCACHE`. Экспорт пишет файл в кэш и копирует его по пути из системного диалога «Сохранить как» (`pickSavePath` + `writeChosenFile`), импорт так же читает через кэш (`readChosenFile`). Asset-протокол (показ картинок с диска) включён в `tauri.conf.json`.
- Команды Rust (`src-tauri/src/files.rs`): `scan_library` (обход библиотеки с размером и mtime за один вызов), `inspect_files` (SHA-256 и размеры по заголовку), `move_to_trash`. Вызываются только из `shared/fs`.
- Миниатюры: `%LOCALAPPDATA%\com.gmhelper.app\thumbs\<sha256>.webp`, создаются лениво (`modules/library/thumbnails.ts`).
- Токены: PNG в `<группа>/_tokens/<арт>.token-<n>.png`, параметры кадрирования в таблице `tokens` (`modules/library/tokenService.ts`, чистая логика в `domain/tokenCrop.ts` и `domain/tokenNames.ts`). В библиотеку файлы пишутся через `writeOwnLibraryFile` (сначала в `$APPCACHE/staging`, потом копирование). Картинки для Canvas загружай с `crossOrigin = "anonymous"`, иначе холст нельзя экспортировать.

## Окружение

- Разработка на Windows 10. Shell — PowerShell. Если `node`/`cargo` не находятся, обнови PATH в сессии: `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`. Учитывай пути с пробелами и кириллицей (имена систем и групп в библиотеке будут на русском).

## Git

- Небольшие коммиты, по одному логическому изменению. Сообщения на английском в стиле Conventional Commits (`feat(library): ...`, `fix(battlemap): ...`).
- Не коммить сгенерированные файлы, `node_modules`, `src-tauri/target`, локальные базы и кэш.
